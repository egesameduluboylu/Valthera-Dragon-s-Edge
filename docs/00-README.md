# Valthera: Dragon's Edge — Tasarım Dokümanları

DragonFable'dan ilham alan, savaş odaklı, tek elle oynanan bir mobil RPG.
Kısa zindan koşuları, sıra tabanlı savaş, sınıf değiştirme ve kombo yetenekleri.

Bu klasör oyunun baştan sona tasarımını içerir. Kod bu dokümanlara göre yazılacak;
tasarım değiştiğinde önce ilgili doküman güncellenir.

## Kısa Özet

- **Tür:** Sıra tabanlı aksiyon RPG, zindan koşusu
- **Platform:** Android (önce), iOS
- **Motor:** Godot 4.x, GDScript
- **Ekran:** Dikey (portrait), tek elle oynanış
- **Oturum süresi:** 3 ila 7 dakika
- **İlk hedef (demo):** 1 sınıf, 1 zindan, 3 düşman, 1 patron
